【重要】所有启动脚本已移至 scripts 文件夹！

  以下提到的所有 .bat 脚本，都在项目根目录的 scripts 文件夹里。
  操作步骤：先打开 scripts 文件夹，再双击对应的 .bat 文件。


【如果你是第一次用，看这里】

  只需要做一件事：
    打开 scripts 文件夹 → 双击运行 01-首次运行-安装并启动.bat

  这个脚本会自动帮你完成：
    ✓ 检查 Python 环境
    ✓ 创建虚拟环境
    ✓ 安装所有依赖
    ✓ 初始化评测用例
    ✓ 启动服务
    ✓ 自动打开浏览器

  第一次运行需要 3-10 分钟（取决于网速），请耐心等待，
  不要关闭弹出的命令行窗口。

  看到浏览器自动打开并显示平台界面，就说明成功了！


【以后每天用，看这里】

  打开 scripts 文件夹 → 双击运行 02-启动服务.bat

  （因为依赖已经装过了，这个会快很多，几秒钟就启动）


【想停止服务，看这里】

  方法一（最简单）：直接关闭那个命令行窗口
  方法二：打开 scripts 文件夹 → 双击运行 03-停止服务.bat


【其他脚本说明】（均在 scripts 文件夹内）

  04-初始化评测用例.bat  →  重新导入30道测试题（一般不用）
  05-打开管理界面.bat    →  只打开浏览器（服务已启动时用）
  06-备份数据.bat        →  备份数据库到 data\backups\
  Docker启动.bat         →  使用 Docker 方式启动（需先装 Docker Desktop）


【重要提醒：关于 .ps1 文件】

  你会看到每个操作都有两个文件：
    01-首次运行-安装并启动.bat   ← 双击这个（启动器）
    01-首次运行-安装并启动.ps1   ← 别双击这个（实际代码）

  .ps1 是脚本的实际代码，双击它会用记事本打开，不会运行。
  你只需要双击 .bat 文件就行，.ps1 会被自动调用。


【常见问题】

  Q: 双击 .bat 后窗口一闪而过？
  A: 在 scripts 文件夹空白处按住 Shift + 右键 → "在此处打开 PowerShell 窗口"，
     然后输入：.\01-首次运行-安装并启动.bat  回车，
     这样窗口不会关，能看到完整的错误信息。

  Q: 提示"没有检测到 Python"？
  A: 去 https://www.python.org/downloads/ 下载安装，
     安装时一定要勾选 "Add Python to PATH"！

  Q: 浏览器打开显示"无法访问此网站"？
  A: 服务还没启动完，等 5 秒刷新一下。
     或者命令行窗口里有报错，把报错信息截图找人帮忙。

  Q: 想换个端口？
  A: 右键编辑 scripts 文件夹里对应的 .ps1 文件（比如 02-启动服务.ps1），
     把里面的 8000 改成其他数字，保存后重新双击 .bat 启动。

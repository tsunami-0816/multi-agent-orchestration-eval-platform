# 多智能体编排与模型评测平台 — 零基础操作手册

> 这份手册是给**完全不懂编程**的人看的。
> **99% 的用户只需要看前四节**，后面的进阶内容可以忽略。

---

## 一、这个项目是干嘛的？

简单说，这是一个**让 AI 自动干活、然后给 AI 打分**的平台：

- **任务编排**：你输入一句话（比如"帮我搜索并总结 AI 最新进展"），系统会自动派出多个 AI 角色（规划者→执行者→审核者→汇总者）协作完成任务。
- **模型评测**：系统自带 30 道测试题，可以批量跑题，然后自动给 AI 的回答打分，最后生成一份可视化报告。

**重要说明**：这个平台**没有注册、没有登录**，打开浏览器就能用。

## 二、运行前唯一要做的准备：装 Python

### 第 1 步：下载 Python

打开浏览器，访问 https://www.python.org/downloads/

点击黄色的 **"Download Python 3.x.x"** 按钮（下载 3.10 或更高版本都行）。

### 第 2 步：安装 Python（关键一步！）

1. 运行下载好的安装包
2. **非常重要**：安装界面最下方有一个 **"Add Python to PATH"** 复选框，**一定要勾选**！
3. 点击 **"Install Now"**
4. 等待安装完成，点击 Close

### 第 3 步：验证安装成功（可选，不放心可以验证）

1. 按 `Win + R`，输入 `cmd`，回车
2. 在命令行窗口里输入：`python --version`，按回车
3. 看到类似 `Python 3.12.0` 就说明成功了
4. 关掉这个命令行窗口就行

> 如果提示"不是内部或外部命令"，说明没勾选 PATH。重新运行 Python 安装包，选 "Modify"，勾选 "Add Python to environment variables"，安装完成后**关掉所有命令行窗口重新打开**。

## 三、【最简单】双击脚本一键启动

项目的 **`scripts` 文件夹**下已经准备好了 6 组脚本，每组包含一个 `.bat`（双击入口）和一个 `.ps1`（实际逻辑）。**你只需要认识前 3 个 `.bat`，双击它们就行，不用管 `.ps1` 文件**：

> **注意**：所有脚本都在 `scripts` 文件夹里，不是在项目根目录。操作时先打开 `scripts` 文件夹，再双击对应的 `.bat`。

| 脚本（双击这个 .bat） | 什么时候用 | 双击后会发生什么 |
|---|---|---|
| **01-首次运行-安装并启动.bat** | 第一次用 | 自动装环境+装依赖+启动+打开浏览器（3-10分钟） |
| **02-启动服务.bat** | 以后每天用 | 快速启动服务+打开浏览器（几秒钟） |
| **03-停止服务.bat** | 想停止时 | 关闭服务（其实直接关窗口也行） |

> 旁边同名的 `.ps1` 文件是脚本的实际代码，**不要双击它**（双击会用记事本打开），只双击 `.bat` 文件。

### 第一次使用（只需要做一次）

1. 打开项目文件夹，进入 **`scripts`** 文件夹
2. 找到 **`01-首次运行-安装并启动.bat`**
3. **双击它**
4. 弹出命令行窗口，开始自动安装，你会看到类似这样的进度：

```
============================================================
   多智能体编排与模型评测平台 - 首次安装并启动
============================================================

[1/6] 检查 Python 环境...
      已检测到 Python 3.12.0

[2/6] 创建虚拟环境（首次运行需要，约 10-30 秒）...
      虚拟环境创建成功

[3/6] 激活虚拟环境...
      已激活

[4/6] 安装项目依赖（首次运行需要，约 3-10 分钟）...
      正在下载依赖，请耐心等待，不要关闭窗口...
```

5. **耐心等待**，不要关闭命令行窗口。安装依赖这一步最久，可能需要 3-10 分钟。
6. 最后服务启动，**浏览器会自动打开**，显示平台界面。
7. 看到界面就说明成功了！命令行窗口**不要关**，关了服务就停了。

### 以后每次使用

1. 进入 `scripts` 文件夹，双击 **`02-启动服务.bat`**
2. 等几秒钟，浏览器自动打开
3. 完事

### 停止服务

- **最简单的方法**：直接关闭那个命令行窗口
- 或者：进入 `scripts` 文件夹，双击 **`03-停止服务.bat`**

## 四、核心主流程走一遍

服务启动后，浏览器会自动打开 `http://localhost:8000`。你会看到顶部有 4 个标签页：

- ⚙️ 任务管理
- 📊 评测管理
- 🔍 轨迹查看
- 📄 报告展示

### 流程 A：创建一个 AI 任务，然后在列表里看到它

这是最核心的操作，对应"创建一条数据 → 列表看得到"。

#### 第 1 步：进入「任务管理」标签页

打开页面后默认就在「任务管理」。如果不在，点一下顶部的 **⚙️ 任务管理**。

#### 第 2 步：填写任务描述

在「创建编排任务」卡片里，找到 **"任务描述"** 输入框（带红色星号的那个），输入一句话，比如：

```
帮我搜索并总结2024年AI领域的三大进展，要求包含多模态、Agent编排和推理优化三个方向
```

其他选项（任务类型、最大轮次、回调URL）保持默认就行，不用管。

#### 第 3 步：点击「提交任务」按钮

点击后，按钮下方会显示创建成功的提示，并给出一个**任务 ID**（一串字母数字）。

> 因为默认是 Mock 模式（模拟 AI），任务会瞬间完成。如果以后换成真实 AI，需要等几秒到几十秒。

#### 第 4 步：在任务列表里看到它

往下滚动页面，找到 **"任务列表"** 区域（如果没看到新任务，点一下列表右上角的 **🔄 刷新** 按钮）。

你刚才创建的任务应该出现在第一行，能看到：
- 任务 ID
- 任务类型（orchestration）
- 状态（completed 表示已完成）
- 创建时间

#### 第 5 步：查看任务详情和轨迹

- 点击任务行的 **"详情"** 按钮，可以看到任务的完整结果
- 点击 **"轨迹"** 按钮，可以看到 AI 各个角色的对话过程
- 也可以切换到顶部 **🔍 轨迹查看** 标签页，输入任务 ID 查看完整的执行链路可视化

---

### 流程 B：跑一次模型评测，生成报告

这是平台的另一个核心功能。

#### 第 1 步：进入「评测管理」标签页

点击顶部的 **📊 评测管理**。

#### 第 2 步：查看可用的测试题

页面下方有「评测用例」区域，能看到系统自带的 30 道测试题，分 6 个类别：
- 研究（research）
- 代码（code）
- 数据（data）
- 写作（writing）
- 推理（reasoning）
- 工具（tool）

#### 第 3 步：创建评测运行

在「创建评测运行」卡片里：
- **运行名称**：随便填，比如 `我的第一次评测`
- **用例类别**：建议选 `研究（research）`（只跑 6 道题，跑得快）；想跑全部就留空
- **模型配置**：保持默认 `deepseek-chat` 就行（只是个记录标签）
- **指定用例 ID**：留空
- 点击 **"创建并开始评测"** 按钮

创建成功后会显示一个**运行 ID**。

#### 第 4 步：在运行列表里看到它

往下滚动到 **"评测运行列表"**，你刚创建的运行就在第一行。能看到：
- 运行名称
- 状态（running 运行中 / completed 已完成）
- 进度（比如 3/6）
- 通过数、平均分

> Mock 模式下很快完成。可以点列表右上角的 **🔄 刷新** 按钮查看最新进度。

#### 第 5 步：查看评测报告

等运行状态变成 `completed` 后：
- 方法一：点击运行行的 **"报告"** 按钮
- 方法二：切换到顶部 **📄 报告展示** 标签页，输入运行 ID，点「查看报告」

你会看到一份可视化报告，包含：
- 总分和各维度得分（准确性、相关性、完整性、格式）
- 每道题的得分详情和评委反馈
- 通过/未通过统计

## 六、【进阶】手动命令行方式

> 这一节是给想了解原理的人看的。**普通用户完全可以跳过**，用上面的双击脚本就够了。

如果你不想用脚本，也可以手动敲命令。以下所有命令都需要先在项目目录下打开命令行（在文件夹地址栏输入 `cmd` 回车）。

### 6.1 创建并激活虚拟环境

```
python -m venv venv
venv\Scripts\activate
```

激活成功后命令行前面会出现 `(venv)`。

### 6.2 安装依赖

```
pip install -r requirements.txt
```

国内网络慢可以用镜像：
```
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 6.3 初始化评测用例

```
python -m app.cli.main init-cases
```

### 6.4 启动服务

```
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

然后浏览器打开 `http://localhost:8000`。

### 6.5 用 curl 调用 API（进阶）

创建任务：
```
curl -X POST http://localhost:8000/api/v1/tasks -H "Content-Type: application/json" -d "{\"input\": \"帮我总结AI最新进展\", \"scenario\": \"orchestration\"}"
```

查看任务列表：
```
curl http://localhost:8000/api/v1/tasks
```

创建评测运行：
```
curl -X POST http://localhost:8000/api/v1/eval/runs -H "Content-Type: application/json" -d "{\"name\": \"命令行评测\", \"category\": \"research\"}"
```

查看评测运行列表：
```
curl http://localhost:8000/api/v1/eval/runs
```

### 6.6 查看所有 API 文档

浏览器打开 `http://localhost:8000/docs`，可以看到所有接口的详细说明，还能直接在页面上测试调用。

## 七、【进阶】Docker 部署方式

> 普通用户跳过这一节。适合电脑上已经装了 Docker Desktop 的人。

### 7.1 一键启动

在项目目录下打开命令行，输入：
```
docker-compose up -d
```

### 7.2 初始化用例

```
docker-compose exec api python -m app.cli.main init-cases
```

### 7.3 访问

浏览器打开 `http://localhost:8000`。

### 7.4 常用命令

```
docker-compose logs -f api    # 查看 API 日志
docker-compose down            # 停止并删除所有容器
docker-compose restart         # 重启所有服务
```

## 八、常见问题

### Q1：双击脚本后命令行窗口一闪而过？

**原因**：脚本执行出错了，但窗口关太快看不到错误。

**解决**：
1. 在脚本所在文件夹的空白处，按住 `Shift` + 鼠标右键
2. 选「在此处打开 PowerShell 窗口」或「在终端中打开」
3. 输入脚本名，比如 `.\01-首次运行-安装并启动.bat`，回车
4. 这样就能看到完整的错误信息了

### Q2：脚本提示"没有检测到 Python"？

**原因**：Python 没装，或者装了但没勾选 PATH。

**解决**：
1. 去 https://www.python.org/downloads/ 下载安装
2. 安装时**一定要勾选 "Add Python to PATH"**
3. 装完后**关掉所有命令行窗口，重新双击脚本**

### Q3：安装依赖特别慢或者报错？

**解决**：脚本已经自动用了清华镜像源。如果还是失败，检查网络连接，或者手动执行：
```
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q4：浏览器打开显示"无法访问此网站"？

**排查顺序**：
1. 服务还没启动完，等 5 秒钟刷新页面
2. 确认命令行窗口还开着，没被关掉
3. 确认命令行窗口里显示了 `Uvicorn running on http://0.0.0.0:8000`
4. 试试在地址栏输入 `http://127.0.0.1:8000`

### Q5：任务创建后状态一直是 pending（等待中），不完成？

**原因**：异步任务队列没启动。

**解决**：
- 本地脚本方式：任务是同步执行的，Mock 模式应该瞬间完成。刷新下列表看看。
- Docker 方式：确认 worker 容器启动了，执行 `docker-compose ps` 查看。

### Q6：想用真实 AI（DeepSeek）怎么配置？

1. 去 https://platform.deepseek.com 注册账号，充值，拿到 API Key
2. 在项目目录下找到 `.env.example` 文件，复制一份改名为 `.env`
3. 用记事本打开 `.env`，修改两行：
   ```
   APP_LLM_PROVIDER=deepseek
   APP_LLM_API_KEY=你的API密钥
   ```
4. 保存文件，重启服务（关命令行窗口，重新双击 02-启动服务.bat）

> 注意：真实 AI 调用会产生费用。平台有预算控制（默认每天 200 元上限，达到 180 元会预警）。

### Q7：数据存在哪里？会丢吗？

所有数据存在项目目录下的 `data\db\app.db` 文件里（SQLite 数据库）。只要不删这个文件，数据就不会丢。

想备份的话，双击 `06-备份数据.bat`，备份文件会存在 `data\backups\` 目录。

### Q8：8000 端口被其他程序占用了怎么办？

1. 进入 `scripts` 文件夹，右键编辑 **`02-启动服务.ps1`**（注意是 .ps1，不是 .bat）
2. 找到最后一行 `uvicorn app.main:app --host 0.0.0.0 --port 8000`
3. 把 `8000` 改成其他数字，比如 `8080`
4. 保存，重新双击 `02-启动服务.bat` 启动
5. 浏览器访问 `http://localhost:8080`

### Q9：想彻底删除重装怎么办？

1. 停止服务（关命令行窗口）
2. 删除项目目录下的 `venv` 文件夹（虚拟环境）
3. 删除 `data\db\app.db` 文件（数据库，注意这会清空所有数据）
4. 重新双击 `01-首次运行-安装并启动.bat`

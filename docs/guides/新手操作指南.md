# 多智能体编排与模型评测平台 — 新手操作指南

> 这份指南是给**完全不懂编程**的用户看的，跟着一步一步做就行。
> 所有操作都在 Windows 系统上进行。

---

## 一、这是个什么平台？

简单说，这是一个让多个 AI 智能体（Agent）一起协作完成任务的平台，还能评测 AI 回答得好不好。

你不需要懂代码，只需要：
1. 双击启动脚本
2. 在网页里输入你想让 AI 做的事
3. 看 AI 们怎么一步步协作完成任务

平台有 4 个主要功能页面：
- **任务管理**：创建一个任务，看多个 AI 怎么协作完成
- **评测管理**：批量测试 AI 在 30 道题上的表现
- **轨迹查看**：看 AI 执行任务的完整过程（每一步说了什么、做了什么）
- **报告展示**：看评测结果的详细报告和图表

## 二、开始前的准备

你只需要在电脑上装一个 **Python**（版本 3.10 或以上）。

### 怎么装 Python？

1. 打开浏览器，访问：https://www.python.org/downloads/
2. 点击黄色的 "Download Python 3.x.x" 按钮下载
3. 双击下载好的安装包
4. **非常重要**：安装界面最下方有一个 "Add Python to PATH" 复选框，**一定要勾选上**！
5. 点击 "Install Now" 等待安装完成
6. 安装完成后，**重启一下电脑**（让环境变量生效）

> 怎么确认装好了？按 `Win + R`，输入 `cmd` 回车，在黑窗口里输入 `python --version` 回车，如果显示版本号就说明装好了。

## 三、最快上手方式（推荐）

### 第 1 步：找到脚本文件

打开项目文件夹 `multi-agent-orchestration-eval-platform`，进入 **`scripts`** 文件夹，你会看到几个以 `.bat` 结尾的脚本文件。

> **注意**：所有启动脚本都在 `scripts` 文件夹里，不是在项目根目录。

### 第 2 步：双击「01-首次运行-安装并启动.bat」

在 `scripts` 文件夹里找到文件 **`01-首次运行-安装并启动.bat`**，**双击它**。

这一个脚本会自动帮你完成所有事情：
- 检查 Python 有没有装好
- 创建独立的 Python 运行环境（不会搞乱你电脑上的其他东西）
- 自动安装项目需要的所有依赖包（**自动使用清华国内镜像，下载快**）
- 自动初始化数据库和 30 条评测用例
- 启动后台服务
- 自动打开浏览器进入平台页面

### 第 3 步：等待启动

- 第一次运行需要 **3-10 分钟**（要下载安装依赖，取决于网速），请耐心等待
- 之后再运行就很快了（几秒钟）
- 你会看到一个蓝色的命令行窗口，里面在滚动文字，这是正常的
- 大约 4 秒后，浏览器会自动打开平台页面

> **注意**：那个蓝色窗口不能关！关了服务就停了。想停止服务时，关闭那个蓝色窗口即可，或者双击运行 `03-停止服务.bat`。

### 第 4 步：开始使用

浏览器打开后，你会看到平台的主界面。接下来看下面的「五、核心主流程操作」。

## 五、核心主流程操作（创建任务 → 看列表 → 看结果）

这是平台最核心的功能，跟着做一遍就能上手。

### 第 1 步：进入「任务管理」页面

启动服务后，浏览器自动打开的页面默认就是「任务管理」页面。
页面顶部有 4 个标签：任务管理、评测管理、轨迹查看、报告展示。
确保你在第一个标签「任务管理」上。

页面右上角有一个状态指示灯：
- 🟢 绿色 = 服务正常
- 🟡 黄色 = 部分异常
- 🔴 红色 = 服务不可用

### 第 2 步：创建一个任务

在页面上方找到「**创建编排任务**」卡片：

1. **任务描述**（必填）：在大文本框里输入你想让 AI 做的事。
   - 示例输入：`帮我搜索并总结2024年AI领域的三大进展，要求包含多模态、Agent编排和推理优化三个方向`
   - 也可以简单点：`用Python写一个快速排序算法，并解释时间复杂度`
   - 字符数限制 1-10000 字
   - 输入时右下角会显示已输入的字符数

2. **任务场景**（可选）：下拉菜单，默认选「编排任务（Orchestration）」就行。

3. **最大轮次**（可选）：AI 最多协作几轮，默认 5，不用改。

4. **回调URL**（可选）：留空就行，普通用户用不到。

5. 点击蓝色的「**🚀 提交任务**」按钮。

### 第 3 步：在任务列表里看到刚创建的任务

提交后，页面下方的「**任务列表**」会自动刷新，你会看到刚创建的任务：

| 列名 | 说明 |
|------|------|
| ID | 任务的唯一编号（一串字符，只显示前 8 位） |
| 任务描述 | 你刚才输入的内容（太长会截断，鼠标悬停看全文） |
| 场景 | orchestration（编排任务） |
| 状态 | 等待中 → 运行中 → 已完成 |
| 创建时间 | 什么时候创建的 |
| 耗时 | 执行花了多长时间 |
| 操作 | 详情 / 取消 / 轨迹 三个按钮 |

**状态变化过程：**
- 刚提交时：`等待中`（黄色标签）
- 开始执行时：`运行中`（蓝色标签）
- 执行完成时：`已完成`（绿色标签）
- 出错时：`失败`（红色标签）

> 小技巧：点击任务列表上方的「⏱ 自动刷新: 关」按钮可以开启自动刷新，每 5 秒自动更新任务状态。也可以点「🔄 刷新」手动刷新。

### 第 4 步：查看任务详情和结果

等任务状态变成「已完成」后：

1. 在任务列表里找到这条任务
2. 点击操作列的「**详情**」按钮
3. 会弹出一个窗口，显示：
   - 任务 ID、状态、场景、创建时间、开始时间、完成时间、耗时
   - 任务描述（你输入的完整内容）
   - **执行结果**（AI 最终给出的答案）
   - 如果出错了，会显示红色的错误信息
4. 弹窗底部有「查看执行轨迹」按钮，可以直接跳转到轨迹页面

### 第 5 步：查看 AI 协作的完整轨迹（最有意思的部分）

这个平台的特色是能看到多个 AI 是怎么一步步协作的：

1. 在任务列表里点击操作列的「**轨迹**」按钮（或者在详情弹窗里点「查看执行轨迹」）
2. 页面会自动跳转到「轨迹查看」标签页，并自动加载该任务的轨迹
3. 你会看到：
   - **顶部统计卡片**：任务状态、消息总数、参与角色数、总耗时
   - **检查点列表**：Planner（规划）→ Executor（执行）→ Reviewer（审核）→ Aggregator（汇总），点击可跳转
   - **消息时间线**：按轮次分组，每个 AI 角色说的话都能看到

**四个 AI 角色的分工：**
- 📋 **Planner（规划者）**：把你的任务拆分成具体步骤
- ⚙️ **Executor（执行者）**：调用工具执行具体步骤（搜索、写代码等）
- 🔍 **Reviewer（审核者）**：检查执行结果好不好，不行就打回重做
- 📝 **Aggregator（汇总者）**：把所有结果整理成最终答案

**操作提示：**
- 点击每一轮的标题可以展开/折叠该轮的详细消息
- 长消息可以点「展开全文」查看完整内容
- 顶部有「全部展开」和「全部折叠」按钮
- 也可以手动在输入框里输入任务 ID，点「查看轨迹」查询

## 六、评测功能操作（进阶）

评测功能可以批量测试 AI 在 30 道标准题上的表现，给出评分和报告。

### 第 1 步：确保评测用例已初始化

如果你是用 `01-首次运行-安装并启动.bat` 启动的，用例已经自动初始化好了。
如果不确定，可以双击运行 `04-初始化评测用例.bat`（已导入的会自动跳过，不会重复）。

### 第 2 步：切换到「评测管理」页面

点击顶部第二个标签「**评测管理**」。

### 第 3 步：创建评测运行

在「**创建评测运行**」卡片里：

1. **运行名称**（必填）：给这次评测起个名字，比如 `第一次测试`
2. **用例类别**（可选）：下拉菜单，选「全部类别（30条）」就行，也可以只测某一类（研究/代码/数据/写作/推理/工具）
3. **模型配置**（可选）：默认 `deepseek-chat`，Mock 模式下不影响结果
4. **指定用例ID**（可选）：留空，测全部用例；想只测某几题就填逗号分隔的 ID
5. 点击蓝色的「**🚀 创建并开始评测**」按钮

### 第 4 步：在评测运行列表里看进度

下方「**评测运行列表**」会显示刚创建的评测：
- 进度条会从 0% 慢慢走到 100%，显示 `已完成数/总数 (百分比)`
- 状态从「运行中」变成「已完成」
- 完成后会显示平均分和通过率
- 运行中的任务可以点「检测」按钮手动触发完成检测

### 第 5 步：查看评测报告

评测完成后：

1. 点击操作列的「**报告**」按钮
2. 页面跳转到「报告展示」标签页，自动加载报告
3. 你会看到：
   - **运行信息卡片**：名称、ID、模型、创建时间，还有「下载 HTML」「下载 JSON」按钮
   - **6 个统计数字**：平均分、通过率、用例总数、通过数、未通过、中位数
   - **四维度评分对比图**：准确性、相关性、完整性、格式（柱状图）
   - **分数分布图**：各分数段的用例数量（柱状图）
   - **用例评分明细表**：每道题的详细得分（准确性/相关性/完整性/格式/综合分）和评审反馈，可按维度排序
4. 可以点「一致性校验」按钮检查数据一致性

## 七、其他常用操作

### 怎么停止服务？

- **最简单**：直接关闭那个蓝色的命令行窗口
- **或者**：双击运行 `03-停止服务.bat`，它会自动找到并停止占用 8000 端口的进程
- **Docker 方式启动的**：运行 `03-停止服务.bat` 也能自动检测并停止 Docker 容器

### 怎么重新启动？

直接双击 `02-启动服务.bat` 就行，因为依赖已经装过了，这次会很快（几秒钟）。

### 怎么用 Docker 部署？

如果你电脑上装了 Docker Desktop：
1. 双击 `Docker启动.bat`
2. 等待构建和启动（首次 3-5 分钟）
3. 自动打开浏览器
4. 停止时运行 `03-停止服务.bat` 或在命令行执行 `docker-compose down`

### 怎么备份数据？

双击运行 `06-备份数据.bat`，备份文件会保存在 `data/backups/` 目录下，文件名带时间戳。

### API 文档在哪？

服务启动后，浏览器访问：http://localhost:8000/docs
这是自动生成的交互式 API 文档（Swagger UI），可以在网页上直接测试每个接口，看请求参数和返回格式。

### 健康检查地址？

http://localhost:8000/api/v1/health
会返回 JSON 格式的状态，包括数据库、Redis、LLM 各组件的状态和版本号。

### 数据存在哪？

所有数据都存在项目文件夹下的 `data/` 目录里：
- `data/db/app.db`：主数据库（SQLite 格式，可用 SQLite 工具打开）
- `data/checkpoints/`：任务执行的检查点快照（每个任务一个子文件夹）
- `data/reports/`：生成的评测报告（HTML 和 JSON 格式）
- `data/logs/`：运行日志
- `data/eval_cases/cases.yaml`：30 条评测用例（YAML 格式，可用记事本编辑）
- `data/backups/`：数据库备份文件

## 八、常见问题 FAQ

### Q1：双击脚本后一闪而过怎么办？

A：说明脚本执行出错了，窗口自动关了。解决方法：
1. 按 `Win + R`，输入 `powershell` 回车
2. 在蓝色窗口里输入 `cd "项目文件夹路径"`（比如 `cd "D:\lg\project\multi-agent-orchestration-eval-platform"`）
3. 输入 `.\01-首次运行-安装并启动.bat` 回车
4. 这样窗口就不会自动关闭，能看到具体的错误信息了

### Q2：提示"没有检测到 Python"怎么办？

A：说明 Python 没装，或者装的时候没勾选 "Add Python to PATH"。
- 重新安装 Python，安装时**务必勾选** "Add Python to PATH"
- 装完重启电脑
- 重启后再双击脚本

### Q3：依赖安装失败怎么办？

A：脚本已经自动使用清华国内镜像源了，如果还是失败：
1. 检查网络连接是否正常
2. 换个时间重试（可能是镜像源临时故障）
3. 如果提示某个包下载失败，可以手动运行 `02-启动服务.bat`，它会检测到依赖不完整并自动重新安装

### Q4：端口 8000 被占用怎么办？

A：说明之前启动过服务没关。
- 运行 `03-停止服务.bat` 自动清理
- 或者找到之前的蓝色/黑色命令行窗口手动关闭
- 然后重新启动

### Q5：任务一直是"等待中"不执行怎么办？

A：这个项目默认不启用 Celery（异步任务队列），任务是同步执行的。
- 刷新一下页面看看状态有没有变
- 如果一直不变，检查蓝色命令行窗口有没有红色的 `ERROR` 报错
- Mock 模式下任务应该很快完成（几秒到几十秒）
- 如果任务量多，可以在 `config.yaml` 里把 `celery.enabled` 改成 `true` 启用异步队列（需要 Redis）

### Q6：想用真实的大模型（DeepSeek）怎么办？

A：
1. 去 https://platform.deepseek.com/ 注册账号，获取 API Key
2. 用记事本打开项目里的 `config.yaml`
3. 找到 `llm:` 下面的 `provider: "mock"`，改成 `provider: "deepseek"`
4. 找到 `deepseek:` 下面的 `api_key: ""`，在引号里填入你的 API Key
5. 保存文件，重启服务（先 `03-停止服务.bat`，再 `02-启动服务.bat`）

> 注意：使用真实模型会产生费用，平台有预算控制（默认每天 200 元上限，达到 180 元预警后自动切换 Mock）。

### Q7：评测用例能自己加或改吗？

A：可以。用记事本打开 `data/eval_cases/cases.yaml`，按照已有格式添加或修改用例，然后运行 `04-初始化评测用例.bat` 重新导入（幂等操作，已存在的会更新）。

每条用例的格式：
```yaml
- id: "case_001"
  category: "research"        # 类别：research/code/data/writing/reasoning/tool
  input: "题目内容"            # 给 AI 的题目
  scoring_criteria: "评分标准"  # 评委打分的依据
  difficulty: 2               # 难度 1-5
  enabled: true               # 是否启用
```

### Q8：蓝色窗口里的日志看不懂怎么办？

A：正常现象，那些是给开发者看的调试日志。你只需要关注：
- 有没有红色的 `ERROR` 字样
- 服务能不能正常访问（浏览器能不能打开页面）
- 任务能不能正常创建和执行
- 如果页面能正常用，窗口里的普通日志可以忽略

### Q9：怎么完全重置（清空所有数据重新开始）？

A：
1. 先停止服务（关闭窗口或运行 `03-停止服务.bat`）
2. 删除项目里的 `data/db/` 文件夹（这是数据库）
3. 可选：删除 `data/checkpoints/`、`data/reports/` 文件夹
4. 重新运行 `01-首次运行-安装并启动.bat`（会自动重建数据库和用例）

### Q10：支持哪些操作系统？

A：这些 `.bat` 脚本是 Windows 专用的。如果你用 Mac 或 Linux：
- 需要手动执行命令：`pip install -r requirements.txt` → `python -m app.cli.main init-cases` → `uvicorn app.main:app --host 0.0.0.0 --port 8000`
- 或者用 Docker 方式（跨平台）：`docker-compose up -d`

## 九、技术信息（给想了解的人）

- **后端**：Python 3.10+ / FastAPI 0.115 / SQLAlchemy 2.0 / SQLite（WAL 模式）
- **异步任务**：Celery + Redis（默认关闭，可在 config.yaml 开启）
- **Agent 编排**：轻量级状态图（Planner → Executor → Reviewer → Aggregator 四阶段流水线）
- **MCP 工具层**：web_search / code_exec / file_rw / db_query 四大工具
- **LLM 网关**：支持 DeepSeek / 通义千问 / Ollama / Mock 四种模式，带重试、计费、预算控制
- **评测框架**：30 条标准用例 + LLM-as-Judge 多维度评分（准确性/相关性/完整性/格式）
- **报告生成**：HTML 可视化报告 + JSON 结构化数据
- **前端**：纯 HTML + CSS + JavaScript（单文件，无需构建，内嵌 Canvas 图表）
- **可观测性**：7 项核心指标 + Prometheus 端点 + 深度健康检查
- **部署**：支持本地直接运行 和 Docker Compose 两种方式
- **默认端口**：8000
- **默认模式**：Mock（无需 API Key，开箱即用）

## 二、真实 LLM 模式实测（v1.0 全是"有条件通过"）

实测任务：`POST /api/v1/tasks {"input":"用三句话介绍杭州西湖，并给一条推荐路线"}`

| 指标 | 目标 | 实测 | 结果 |
|---|---|---|---|
| 端到端耗时 | P50 ≤ 30s, P95 ≤ 90s | 60 秒（含 14 次 LLM 调用 + 8 轮 executor/reviewer） | ✅ P95 达标 |
| LLM 调用次数 | 四阶段全跑 | 14 次真实 qwen-plus 调用（planner 1 + executor/reviewer 循环 12 + aggregator 1） | ✅ |
| Token 计费 | 记录 usage | 总 input 2314 / output 1540，费用 0.006 元 | ✅ 计费链路通 |
| 任务状态回写 | completed | status=completed, started_at/completed_at 均有值 | ✅ |
| 消息持久化 | trace 可回放 | 17 条消息（含 agent_role/message_type/round_number），18 个检查点 | ✅ |
| 错误兜底 | MCP 工具失败不拖垮主流程 | executor 调用 MCP Server 失败后，aggregator 基于已有知识直接生成最终答案 | ✅ 优雅降级 |
